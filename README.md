# 延时回响 · Delayed Echo（游戏）

一款以「足迹记录 + 回响回放」为核心的 2D 物理解谜平台跳跃游戏。玩家走过的每一步都会被世界记住，攒够足迹后可以释放一个「影子」，让几秒钟前的自己沿着完全相同的路线循环回放，替玩家踩下此刻踩不到的机关。

> 纯前端（原生 HTML / CSS / JavaScript），无框架、无构建、无后端，**双击 index.html 即可运行**。

---

## 部署到 GitHub Pages

本仓库要上传的是 **`index.html` + `audio/` 目录 + `README.md`**（音频为独立 mp3 文件，按需加载，首页只需下载 ~260 KB 的 HTML）。

```bash
git init
git add index.html audio README.md
git commit -m "延时回响 Delayed Echo"
git remote add origin https://github.com/<你的用户名>/delayed-echo-game.git
git push -u origin main
```

然后在仓库 **Settings → Pages** 里把 Source 选成 `main` 分支 / `root`，访问：

```
https://<你的用户名>.github.io/delayed-echo-game/
```

**不需要**任何构建步骤、npm、base path 配置。页面自包含、资源走相对路径，双击 `index.html` 也能离线运行（本地 `file://` 下音乐同样正常播放）。

> `dev/` 目录是开发脚本与素材，**不参与运行、不需要上传**（仓库体积小、页面加载快）。

```bash
cd dev/scripts
node frame.js 名字 390 844 "touch=1&auto=1"     # 精确手机视口截图 → dev/_shot/
node shot.js  名字 844 390 ""  "touch=1&auto=1" # 直接页面截图（可注入脚本）
```

## 手机 / 触屏适配

**桌面端一行都没改**：键盘（A/D、空格、R、F、ESC）与整页布局保持原样。触屏是另加的一层，靠设备自动判断。

| 项目 | 桌面 | 手机 / 平板 |
|---|---|---|
| 走 | `A` / `D`、方向键 | 左下两个圆碟 **‹ ›**：按住就走，拇指向另一半滑过去自动换向（不用抬手） |
| 跳 | 空格 | 右下 **↗** 圆碟 |
| 放回响 | `R` | 它左边 **带数字的圈**：数字就是当前足迹，够 5 步才会亮起来 |
| 看告示 | `F` | **直接点画面里那块牌子**（走近时牌子上浮出气泡「点一下」） |
| 暂停 | `ESC` | 右上角 ❚❚ |

- **按键是「磨砂玻璃」**：半透明 + `backdrop-filter` 轻度模糊 + 一道内高光，底下的天空、地面、砖块都还看得见，只是被滤柔了一点 —— 压在画面上像 HUD，不像贴纸。按下时染成游戏主色（薰衣草 `#8b81c0`）。
- **按键贴在画布上**，不是贴在屏幕上：`fit()` 把按键层的盒子设成画布矩形，横屏就落在画布四角；竖屏（预览面板多半是竖的）横向对齐画布、纵向贴着画布下沿 —— 「画布 + 按键」作为一整块竖直居中，不会出现「画布在上、按键孤零零挂在屏幕底」。
- **按键做得小，判定做得大**：看得见的碟子只有 28–44px，外面还有一圈透明的判定盒（`.tb` 比 `::before` 的视觉碟大 12–14px），拇指按边缘也算按到。
- **不和方块重合**：横屏时碟子压在地面下方那条空处（`bottom:2px`），尺寸跟着画布走 `clamp(42, min(画布高×0.15, 画布宽×0.07), 56)`；竖屏时碟子在画布下方的空白里，不受画布限制，可以给到拇指舒服的 `clamp(48, 屏宽×0.135, 64)`。
- **回响圈只显示一个大字**：还没攒足迹时是「回」，攒到步数就变成数字；够 5 步时整圈变成实线紫边。
- **自动识别**：`(pointer:coarse)` + 触摸能力同时成立才启用触屏层；`?touch=1` / `?touch=0` 可强制切换（调试、演示、触屏笔记本）。
- **进游戏顺手全屏 + 锁横屏**（`screen.orientation.lock('landscape')`，不支持的浏览器静默跳过）；暂停面板里也有「全屏」开关。锁不上也不影响玩 —— 竖屏版式是完整可玩的。
- **弹窗**：手机上规则 / 选关 / 告示面板都可滚动、按钮加大；横屏选关页是**三列 × 两行**，一屏看完 6 关 + 3 个存档位。
- **文案**：触屏上所有键盘提示（「空格 跳跃」「按 R」…）自动换成按键说法；画布里的「按 F 键」气泡在触屏上改画「点一下」。

> 触屏按键不是另一套逻辑：按下时调用的是 `pressDir()` / `pressJump()` / `releaseShadow()`，和键盘走同一条路，**物理手感、跳跃缓冲、落地锁全部一致**。

## 核心机制速览

- **足迹记录**：走一格或跳一次算 1 步，先进先出，上限 10 步（第 3 关为无限）
- **回响（影子）**：满 5 步可释放（键盘 `R` / 手机「回响」键），影子沿你走过的原路回放，替你去踩机关
- **第 6 关换幕**：只认幕门，不看音乐进度——走进尽头那道拱门，世界才闪一下换成下一张图

## 配套仓库

关卡编辑器在**另一个独立仓库**：`delayed-echo-editor`。

两者通过浏览器 `localStorage` 通信，因此**必须在同一域名下访问**（GitHub Pages 上两个仓库同属 `用户名.github.io`，天然满足）。在编辑器顶部的「游戏页」输入框填上游戏网址，即可一键发送关卡并自动打开。

### 我的地图：三个存档位

编辑器「发送到游戏」不是一次性投递，而是**存档**：

1. 编辑器把地图写进 `delayed_echo_inbox`（收件箱）
2. 游戏启动时自动把它搬进 `delayed_echo_slots` 的**三个存档位**之一，并清空收件箱
3. 之后打开「选择关卡」，列表下方固定出现 **我 的 地 图 · 三 个 存 档 位**：有图的格子可以「进入 / 删除」，空格子显示提示
4. 删除会在弹窗里二次确认（写明要删的是哪一张、多大多久前存的），点「确认删除」才真删；「取消」或 `ESC` 都不动数据
5. 三个都满了不会静默覆盖——发送时游戏会提示你先删一个

编辑器的「存档位」下拉可指定发到 ①/②/③（覆盖那一格）；选「自动」则放进第一个空格。

> **存档只在本机本浏览器**：`localStorage` 跟着「设备 + 浏览器 + 域名」走，换电脑 / 换浏览器 / 无痕窗口都读不到。跨设备请用编辑器的「下载 .txt」→ 游戏里「导入地图」粘文本。
